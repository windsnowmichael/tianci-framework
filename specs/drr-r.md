# DRR-R 断裂段重定向：规格（Specs 版）

> 本文档是把第94天《TDP-CP与DRR-R方法论边界规范_v1.0.md》的 **DRR-R 可执行化规格** 沉淀进本包的规格文件。
> 代码见 `tianci/drr.py`（接口 `drr_r(handoff)`）；典型输入为 `tianci/cp.py` 的 `tdp_cp()` 移交包。

---

## 1. 边界裁定：`[R: DRR-only]`

v7.0《天赐范式算子与公式大全》§1.2 将基础算子流写作 **Θ→Γ→[R?]→Σ→Φ→τ**，
其中 `[R?]` 是悬置标注：R 算子在基础流中的位置与激活域未定。

**本包（v0.2.0 起）裁定：`[R?]` 定标为 `[R: DRR-only]`。** 依据为第94天
《TDP-CP与DRR-R方法论边界规范_v1.0.md》§2.1：

> DRR-R（Deep Reverse Redirection - Reception-type）是**断裂段的处理工具**。

即：

- **R 属于 DRR-R（断裂段），不属于 TDP-CP（白箱段）**。白箱段
  （Φ_total ≥ 0.7，路径全透明）R 明确不激活——白箱段无需外部输入。
- 基础流 Θ→Γ→Σ→Φ→τ 的结构印记推演（TDP-CP）与 R 的激活（DRR-R）
  是前后两段：**先推演，推不动（移交）才激活 R**。
- 这是层级裁定，不修改 v7.0 归档原文；归档材料是历史事实，本规格只负责
  在本仓库内的可执行语义。

## 2. 六层结构与执行顺序

DRR-R 对移交的断裂点按固定六层执行（94天 §2.3），顺序不可交换：

| 层 | 名称 | 任务 | 本包对应 |
|---|---|---|---|
| L1 | 直接原因 | 定位表面触发因素 | `Θ_DRR溯源` → 断裂点 reason 摘录 |
| L2 | 结构原因 | 定位系统性的结构缺陷 | `Γ_DRR拓扑` → 断裂点按步骤类别归并 |
| L3 | 存在性原因 | 定位根结构的前提条件 | `Σ_DRR根因` → derivable 判定 |
| — | R 激活 | L3 无法从内部推导时接收外部输入 | `R(Ψ_A): α(x) ↦ α(x)·f(Ψ_A(x))` |
| — | 重定向 | 从断裂点出发指向新方向 | `Ω_DRR` → redirect 结论 |
| — | 预言 | 输出可证伪的下一步 | `τ_DRR` → falsifiable 列表 |

## 3. R 激活判据（由推导路径决定，不由难度决定）

94天 §2.4：

> **R_i = 1** if Θ_DRR(i) = "外部输入不可回避"
> **R_i = 0** if Θ_DRR(i) = "可从系统内部推导"

本包可执行化：判据是**是否存在形式化推导路径**——

- 断裂点可从系统内部推导（存在形式化推导路径）→ `R_OFF = 0`
- 外部输入不可回避（无内部推导路径）→ `R_ON = 1`，此时断裂点必须能
  给出外部输入源 `r_source`（等价于 R(Ψ_A) 中的 Ψ_A）
- 判定**不**依据难度、重要性或直觉；找不到推导路径就说没有，不硬推。

## 4. 边界条件与终极断裂

94天 §2.2：

> 当R算子无法找到外部输入源时，DRR-R标记为"终极断裂"，输出不可证伪的终止声明。

本包 `drr_r`：

- 断裂点标记 `R_ON` 但无 `r_source` → `ultimate_break = True`，
  `verdict = "终极断裂"`，`termination` 给出不可证伪终止声明，
  `falsifiable` 输出为空（不硬凑可证伪预言）。
- **输入契约**（任务单 C4）：`drr_r(handoff)` 必须携带非空 `falsifiable`
  列表；缺失或为空直接 `raise ValueError`，不静默降级、不自己编造预言。

## 5. 算子交换关系（94天 §2.5）

```
[L1, L2] = 0        // 直接原因和结构原因可逆推
[L2, L3] ≠ 0        // 结构原因和存在性原因不可逆（存在性更深层）
[L3, R] ≠ 0         // 存在性原因必须在 R 激活之前（先追到根，再判断）
[R, Ω_DRR] = 0      // R 激活和方向选择可交换（但方向选择依赖 R 的结果）
[Ω_DRR, τ_DRR] ≠ 0  // 方向选择必须在熔断之前（先定方向，再终止当前路径）
```

执行顺序按交换关系约束：`L1 → L2 → L3 → R → Ω_DRR → τ_DRR`。
